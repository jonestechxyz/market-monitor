Certificates from a spreadsheet

200 certificates from one spreadsheet

You have a list of assets and you need the same document for each one: a certificate of conformity, a handover sheet, a test record. Write it once, and let the list fill in the rest.

How it works

  1. Keep the asset list in a spreadsheet. One row per asset, one column per detail, with a name at the top of each column.
  2. Write the certificate once, in Word. Where a detail changes, type the column name in double curly brackets, for example {{ serial_no }}.
  3. Drop both files below. You get back a separate, correctly named Word file for every row, plus a register of what was made.
  4. A person checks and signs. This fills in details. It does not approve anything, and a signature line should stay empty until someone has checked.

Good to know

Two extra placeholders are always available: {{ certificate_no }} gives each document the next number, and {{ issue_date }} gives today's date.

Rows with gaps are held back. If a row has an empty cell that the template needs, no document is made for it. It is listed in the register with the reason, so a half-filled certificate never goes out.

Dates and numbers appear as they look in Excel. Format the column the way you want it printed.

Large pictures in the template make every file large. Shrink a logo before you put it in.
